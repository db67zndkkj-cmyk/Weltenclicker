Privacy Notice

The German version is authoritative.

We process a random session/profile ID, chosen username, game progress, mascot, shield expiry, technical connection data and a short-lived SHA-256 hash derived from IP address and user agent for anti-abuse rate limiting. Payment card data is handled by Stripe, not stored by Weltenclicker.

Your username, mascot, personal world count and active shield status may appear publicly. Session storage is used for required session state; persistent local storage of profile ID and language is optional. We currently do not use advertising or analytics cookies.

Creators may optionally connect Twitch via Twitch OAuth and Supabase Auth; the service may use Twitch login name, display name and profile image to verify community ownership. No Twitch email scope is requested for this purpose.

Vercel provides hosting, Supabase provides database/realtime/backend services, Stripe provides payments, and jsDelivr delivers the pinned Supabase browser library. International transfers may occur under applicable safeguards.
